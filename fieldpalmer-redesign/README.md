# Field Palmer website redesign

Static front-end concept built around Field Palmer's existing brand colours, current public business information and live Field Palmer listing/service links.

## Files
- `index.html` — new homepage
- `properties.html` — sales/rent gateway
- `services.html` — service overview
- `about.html` — company positioning
- `contact.html` — offices + enquiry routing
- `404.html`, `robots.txt`, `sitemap.xml`
- `styles.css`, `script.js`

## Production notes
- Forms currently route to the selected Field Palmer email through the visitor's mail client. Connect the same form UI to the production CRM or form endpoint before launch.
- Property search and key CTAs link to Field Palmer's current live website so listing data remains live.
- Remote images are used in this prototype. Host optimized local copies/CDN variants for production.
- Validate any live business/accreditation details immediately before launch.
